# Colisão de mapas CS2

Coloca aqui os ficheiros `.tri` produzidos pelo `cs2-phys-extractor`.

O nome deve corresponder ao mapa reportado pelo CS2, por exemplo:

- `de_mirage.tri`
- `de_inferno.tri`
- `de_dust2.tri`

Esta pasta contém apenas geometria de colisão para trajetória; os offsets continuam em `data/`.
