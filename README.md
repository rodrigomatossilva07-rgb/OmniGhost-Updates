## Sobre o OMNIGHOST

O **OMNIGHOST** é um launcher multi-jogo para Windows, desenvolvido com foco numa experiência rápida, organizada e consistente.

A aplicação reúne a biblioteca, os módulos disponíveis e o histórico de atualizações numa única interface, mantendo a verificação de novas versões em segundo plano sem bloquear a utilização normal do launcher.

Este repositório é o canal oficial de distribuição das versões públicas do OMNIGHOST.

---

## Principais funcionalidades

- Biblioteca centralizada para jogos e respetivos módulos.
- Interface moderna com tema escuro e identidade visual dourada.
- Pesquisa, filtros e organização de conteúdo.
- Página de atualizações baseada em alterações reais publicadas.
- Histórico separado por versão, módulo e categoria.
- Verificação automática de novas versões em segundo plano.
- Atualizações opcionais ou obrigatórias conforme a versão mínima suportada.
- Download com validação de tamanho e hash SHA-256.
- Cache local para manter informações disponíveis quando estiver offline.
- Sistema de lançamento e gestão dos jogos integrados.
- Arquitetura preparada para futuras integrações.

## Instalação

1. Abre a página da [release mais recente](https://github.com/rodrigomatossilva07-rgb/OmniGhost-Updates/releases/latest).
2. Na secção **Assets**, descarrega o ficheiro `OmniGhost.zip`.
3. Extrai todo o conteúdo para uma pasta à tua escolha.
4. Executa `OmniGhost.exe`.

> [!IMPORTANT]
> Não executes o programa diretamente dentro do ficheiro ZIP. Extrai primeiro todo o conteúdo para garantir que os recursos necessários ficam disponíveis.
