Sobre o projeto

O OMNIGHOST é um launcher multi-jogo para Windows desenvolvido com foco numa experiência simples, rápida e consistente.

A aplicação centraliza a biblioteca, integra módulos específicos para diferentes jogos e mantém o utilizador informado através de uma página de atualizações baseada em changelogs reais.

Este repositório é utilizado para distribuir as versões oficiais do launcher e os ficheiros necessários ao sistema de atualização automática.

Funcionalidades

Biblioteca centralizada para jogos e respetivos módulos.

Interface moderna em tema escuro com identidade visual dourada.

Pesquisa, filtros e organização de conteúdo.

Página de atualizações com histórico real por versão e componente.

Verificação automática de novas versões em segundo plano.

Atualizações opcionais ou obrigatórias conforme a versão mínima suportada.

Download com validação de tamanho e SHA-256.

Cache local para manter informações disponíveis sem ligação à Internet.

Notas de lançamento organizadas por categoria.

Suporte a futuras integrações sem misturar a lógica de cada jogo.

Instalação

Abre a página da versão mais recente.

Descarrega o ficheiro OmniGhost.zip.

Extrai todo o conteúdo para uma pasta à tua escolha.

Executa OmniGhost.exe.

Não executes o programa diretamente de dentro do ficheiro ZIP. Extrai primeiro todos os ficheiros para garantir que os recursos necessários ficam disponíveis.

Atualizações automáticas

Ao iniciar, o launcher verifica em segundo plano se existe uma versão mais recente.

Quando uma atualização está disponível, o sistema:

Consulta o manifesto oficial da release mais recente.

Compara a versão instalada com a versão publicada.

Descarrega o pacote indicado.

Confirma o tamanho e o hash SHA-256.

Prepara a substituição dos ficheiros.

Reinicia o launcher na nova versão.

Uma falha de Internet não impede a abertura normal da aplicação.

Requisitos

Windows 10 ou Windows 11.

Sistema operativo de 64 bits.

Ligação à Internet para procurar e descarregar novas versões.

Espaço disponível para extrair o pacote e criar cópias temporárias durante uma atualização.

Integridade das versões

As versões publicadas incluem informação de tamanho e hash SHA-256 no manifesto update.json.

O launcher valida o pacote antes da instalação. Caso os valores não correspondam, a atualização é interrompida e os ficheiros atuais são preservados.

Estado do projeto

O OMNIGHOST encontra-se em desenvolvimento ativo. Funcionalidades, módulos suportados e requisitos podem mudar entre versões.

Suporte

Ao reportar um problema, inclui:

versão instalada;

versão do Windows;

descrição do comportamento;

passos para reproduzir;

mensagem apresentada pelo launcher;

logs relevantes, sem dados pessoais ou credenciais.

Não publiques tokens, passwords ou outras informações sensíveis.

Aviso

OMNIGHOST é um projeto independente. As marcas, nomes e logótipos de jogos ou empresas mencionados pertencem aos respetivos proprietários.
