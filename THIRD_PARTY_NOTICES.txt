Third-party components
======================

This source tree includes third-party components. Before redistribution, preserve
the notices required by each upstream project and verify the exact license terms
that apply to the binaries/plugins actually shipped.

Declared upstream project licenses (reference only)
---------------------------------------------------
MemProcFS
  Upstream: https://github.com/ufrisk/MemProcFS
  Declared source license: GNU Affero General Public License v3.0 (AGPL-3.0).
  Upstream also states that some bundled dependencies/plugins and Microsoft
  redistributables use separate licenses.

LeechCore
  Upstream: https://github.com/ufrisk/LeechCore
  Declared repository license: GNU General Public License v3.0 (GPL-3.0).

CS2 WebRadar frontend
  Upstream: https://github.com/clauadv/cs2_webradar
  Declared source license in the imported notice: GPL-3.0.
  The local notice is src/games/Cs2/radar_webapp/NOTICE.txt.

Tiny PNG Output in the bundled KeyAuth static library
  Upstream: https://www.nayuki.io/page/tiny-png-output
  The local header declares LGPL-3.0-or-later. The binary contains TinyPngOut.
  Distribution obligations for static linking remain to be resolved.

cloudflared
  Upstream: https://github.com/cloudflare/cloudflared
  Version bundled: 2026.8.2 (Windows x64).
  Declared repository license: Apache License 2.0 (Apache-2.0).
  The signed helper is embedded in OmniGhost and materialized only in the
  application-controlled private runtime when a public radar link is requested.

KeyAuth C++ SDK
  Upstream: https://github.com/KeyAuth/KeyAuth-CPP-Example
  Bundled under: keyauth/x64
  Preserve the upstream licence and notices included with the SDK and its
  bundled curl, libsodium, nlohmann/json and QR-code dependencies.

Dear ImGui and other bundled components
  Keep the license/notice information supplied with the corresponding upstream
  source or asset. Do not infer one license for every third-party file.

The source-tree audit is in docs/DEPENDENCY_LICENSE_AUDIT.md. A Publish package
also generates a build-specific CycloneDX SBOM.

This file records upstream declarations for engineering/compliance tracking; it
is not legal advice and does not replace a distribution-specific license review.
